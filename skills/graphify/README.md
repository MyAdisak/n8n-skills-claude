# graphify Skill

Teaches how to use [graphify](https://pypi.org/project/graphifyy/) to visualize and explore n8n-skills codebases as knowledge graphs.

## What It Covers

- Installation (uv, pipx, pip)
- Building knowledge graphs from n8n-skills directories
- Querying skill relationships and dependencies
- Generating architecture diagrams
- Auto-rebuild on git commits

## Activates When

- "Visualize my n8n-skills codebase"
- "Map relationships between skills"
- "Generate architecture diagram"
- "Understand codebase structure"
- "How do skills connect?"

## Files

- `SKILL.md` — Main guidance with installation, commands, and n8n-skills use cases
